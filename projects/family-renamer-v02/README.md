# Family Renamer V02

A batch-renaming tool for bringing Revit family and type names into a consistent project standard.

## Problem

Large Revit libraries often contain inconsistent, duplicated, or outdated names. Manual renaming is slow, difficult to review, and prone to typing errors.

## Solution

Family Renamer V02 prepares and applies batch renaming using configurable rules or data imported from CSV/XLSX files. Users can filter the dataset and review proposed changes before applying them.

## Key capabilities

- batch renaming of families and types;
- search and filtering;
- CSV/XLSX import and export;
- validation before changes;
- counters and operation summaries;
- presets for spreadsheet-based workflows.

## Business value

- supports consistent naming standards;
- reduces repetitive manual work;
- lowers the risk of naming errors;
- makes family libraries easier to review and maintain.

## Technology

Revit API · C# · .NET · WPF · MVVM

## Status

**In development.** The main workflow is implemented; the latest build and supported Revit versions are being verified.
