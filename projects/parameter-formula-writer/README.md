# Parameter Formula Writer

A Revit family tool for applying and updating parameter formulas in a controlled batch workflow.

## Problem

Entering the same formulas across many families is repetitive and prone to inconsistent expressions or typing errors, especially when nested content is involved.

## Solution

Parameter Formula Writer lets users select families, parameters, and processing scope, then write or update formulas across host and nested-family workflows.

## Key capabilities

- selection of target families and parameters;
- formula entry and updating;
- host and nested-family scope;
- controlled batch processing;
- validation and result review.

## Business value

- accelerates family-library standardisation;
- reduces repetitive formula editing;
- improves consistency across families;
- lowers the risk of manual mistakes.

## Technology

Revit API · C# · .NET · WPF · MVVM
