# Revit Export Tool

A multi-format export tool designed to make the preparation of BIM deliverables faster, clearer, and more consistent.

## Problem

Exporting models and sheets to several formats requires repetitive setup and manual checking. Across multiple models or Revit versions, it becomes easy to miss a required file or apply inconsistent settings.

## Solution

Revit Export Tool brings the main export workflows into one interface and supports repeatable delivery preparation without switching between multiple Revit dialogs.

## Key capabilities

- DWG, NWC, IFC, PDF, and image export;
- consistent export configuration;
- structured multi-version support for Revit 2022–2025;
- WPF interface for preparing deliverables.

## Business value

- reduces repetitive export operations;
- lowers the risk of missing deliverables;
- supports consistent project outputs;
- makes the process easier to review and repeat.

## Technology

Revit API · C# · .NET · WPF · MVVM

## Status

**Testing and refinement.** Core export modules are implemented. Runtime validation for Revit 2025 and parts of the PDF workflow are still in progress.
