# Revit Plugins Portfolio

Revit API tools created by **Daria Zimovets** to automate repetitive BIM tasks, improve model-data quality, and make Revit workflows more reliable.

I am a BIM Specialist with a background in structural engineering and multidisciplinary BIM workflows. My development work focuses on practical problems encountered by Revit users and BIM teams.

## Selected projects

| Project | What it does | Technology | Status |
|---|---|---|---|
| [Revit Export Tool](projects/revit-export-tool/README.md) | Brings DWG, NWC, IFC, PDF, and image export workflows into one interface | Revit API, C#, .NET, WPF, MVVM | Testing and refinement |
| [Family Renamer V02](projects/family-renamer-v02/README.md) | Batch-renames Revit families and types using configurable rules and spreadsheet data | Revit API, C#, .NET, WPF, MVVM | In development |
| [Parameter Change Sync](projects/parameter-change-sync/README.md) | Transfers and synchronizes parameter values across a controlled model scope | Revit API, C#, .NET, WPF, MVVM | In development |
| [Parameter Cleaner](projects/parameter-cleaner/README.md) | Analyses parameters and supports controlled cleanup with safety checks | Revit API, C#, .NET, WPF, MVVM | Testing |
| [Parameter Formula Writer](projects/parameter-formula-writer/README.md) | Automates formula entry and updates in Revit family parameters | Revit API, C#, .NET, WPF, MVVM | In development |
| [Revit API Sandbox](projects/revit-api-sandbox/README.md) | Provides an in-Revit environment for rapid API experiments and script testing | Revit API, C#, Python | Working prototype |

## Areas of focus
